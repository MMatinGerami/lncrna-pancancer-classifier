# lncrna-pancancer-classifier

Can long non-coding RNAs alone tell which tissue a tumour came from? I trained classifiers on the
lncRNA expression of 9,337 TCGA tumours from 33 cancer types and compared them with the same
models on protein-coding genes.

The motivation is cancer of unknown primary, and the fact that lncRNAs are more tissue-specific
than most protein-coding genes ([Yan et al., 2015](https://doi.org/10.1016/j.ccell.2015.09.006)).

## Main results

- Logistic regression on 2,000 lncRNAs: macro-F1 0.946 (95% CI 0.928–0.959) and top-3 accuracy
  0.996 on 1,868 held-out tumours. Protein-coding genes do about as well (0.935); the difference
  is small and significant for only one of the three classifiers.
- 500 lncRNAs are enough (cross-validated macro-F1 0.946).
- Most errors are between related cancers: rectum and colon, oesophagus and stomach,
  cholangiocarcinoma and pancreas.
- Trained on primary tumours only, the model assigns 93% of 364 melanoma metastases from unseen
  patients to skin.
- On an external metastasis cohort (MET500, 437 biopsies) only the protein-coding model can be
  tested, because the public matrix has no lncRNAs: 66% top-1 and 82% top-3, with overconfident
  probabilities.
- SHAP recovers known tissue-restricted lncRNAs, for example LINC00518 for melanoma and PTCSC3 and
  NKX2-1-AS1 for thyroid.

Figures and tables for every analysis are in [docs/results.md](docs/results.md).

## Usage

```bash
uv sync
make data    # TCGA from UCSC Xena and GENCODE v23, about 750 MB
make all     # every analysis and figure
make test
```

Predicting new samples:

```bash
uv run lncpan predict new_samples.parquet --alpha 0.1
```

## Limitations

- All tumours come from TCGA, so centre and batch effects may inflate performance.
- The metastasis result covers one cancer type (melanoma).
- Bulk tissue: part of the signal comes from stroma and immune cells, not the tumour.
- SHAP ranks what the model uses; it does not show a functional role.

## Data

TCGA expression re-processed with Toil ([Vivian et al., 2017](https://doi.org/10.1038/nbt.3772)),
from UCSC Xena ([Goldman et al., 2020](https://doi.org/10.1038/s41587-020-0546-8)); clinical labels
from [Liu et al., 2018](https://doi.org/10.1016/j.cell.2018.02.052); annotation GENCODE v23. The
results are based upon data generated by the TCGA Research Network: https://www.cancer.gov/tcga.
